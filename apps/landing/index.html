为什么是 Inversion

不是又一个 ChatGPT 套壳。

一个观点,一个产品

市面上的 AI 决策工具都试图"什么都能问"。我们只做一件事:把你脑子里的"乐观偏差"撬开,让你看清失败的路径。一个工具做透,胜过十个工具凑合。

提示词是核心壁垒

同样调用 Claude API,普通提示词给你"准备不充分"这种废话。我们的提示词要求每条失败路径都绑定用户具体情况,并输出可执行的避险动作。

本地优先,隐私至上

你的决策很私密。所有数据存在你自己的设备上,我们看不到。BYOK 模式让你用自己的 API Key,我们不当中间商。

不止预测,还会复盘

30 天后,App 会提醒你回来:这些失败真的发生了吗?长期形成你的个人决策档案,看清自己在哪类决策上系统性出错。

常见问题

还有些疑虑?

这和直接问 ChatGPT 有什么区别?

区别是结构化和深度。ChatGPT 给你的是模糊的"注意以下几点",我们给你的是 20 条按可能性 × 杀伤力排序、带因果链、带行动项的失败路径。你也可以把我们看作"提示词工程的成品",省去你自己调几十次提示词的时间。

会不会让我变得太悲观,什么都不敢做?

恰恰相反。研究表明,事前做过 pre-mortem 的人,执行力反而更强。因为你不再被未知的恐惧拖累,而是把恐惧变成了清单。看完 20 种失败路径之后,你会比开始时更冷静、更有准备。

为什么是 20 条,不是 10 条或 50 条?

少于 15 条覆盖不全,容易遗漏关键风险;多于 25 条用户会失去耐心,而且 AI 会开始凑数。20 是我们测试出的最佳数字——足够全面,又能在 5 分钟内读完。

BYOK(自带 API Key)怎么操作?

v0.1 alpha 支持 DeepSeek（每月有免费额度，国内访问稳定）。从 platform.deepseek.com 申请 key，粘贴到 App 设置里即可。Key 会安全存储在 Windows Credential Manager 中，永不上传。Claude 支持将在 v0.2 上线。

我的数据安全吗?

v0.1 alpha：所有决策数据以本地 JSON 文件存储（位置：%APPDATA%\com.inversion.app\decisions.json），不上传我们任何服务器。你可以随时打开、备份、删除。API key 单独走系统钥匙串加密存储。
