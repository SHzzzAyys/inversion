欢迎使用 Inversion

Inversion 是本地 App，不收集你的决策数据。
但 AI 推演需要调用大模型——所以你要带自己的 API key（BYOK）。
Key 只存在你电脑的系统钥匙串里，永不上传。

从 DeepSeek 控制台 申请 key（每月有免费额度）

为什么要 BYOK？为什么不直接给我做付费版？

付费版要做支付、要承担合规、要预估流量——这些都会让 v0.1 阶段太重。 BYOK 模式让我们先验证"产品本身有没有用"，而不是"商业模式能不能跑"。 未来 Pro 版会代付 API 费用，但要等 v0.4。
