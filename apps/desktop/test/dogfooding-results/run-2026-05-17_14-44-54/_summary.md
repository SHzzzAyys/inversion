### 1. 独立开发者：把产品开源还是闭源

> 我做了一个反演推演 App 叫 Inversion，桌面端 Tauri 写的，已完成完整 alpha 闭环。在考虑是开源到 GitHub（求 star + 社区 + GTM 漏斗），还是闭源走付费订阅…

**第一条致命**：被大团队1周内抄袭复制

因为代码仅200行Rust+1000行JS且技术壁垒弱，所以被技术更强的团队一周内抄袭，导致商业价值归零。

**第一条避险**：本周三前在 GitHub 创建私有仓库并提交代码

本周三前在 GitHub 创建私有仓库，将当前代码（200行 Rust + 1000行 JS）推上去，设置私有。确保本地有完整备份，避免代码泄露。

完整报告：[case-01-opensource.md](./case-01-opensource.md)

### 2. 异地恋 3 年要不要现在结婚

> 我和女朋友异地 3 年，她在杭州，我在上海。我 30 岁她 28，双方家长都开始施压结婚。我们感情稳定但有几个分歧。…

**第一条致命**：你近3年不想要孩子，而她想要孩子

她28岁且明确想要孩子，而你至少近3年不想要，时间错位将导致她感到被拖延，最终因生育窗口焦虑而分手。

**第一条避险**：与女友进行一次正式沟通

本周六（5/18）晚上视频通话至少1小时，明确说出你近3年不想要孩子的具体理由（如职业规划、经济准备），并询问她是否愿意接受先订婚同居1年再讨论生育时间表。结束后用备忘录记录双方结论。

完整报告：[case-02-marriage.md](./case-02-marriage.md)

### 3. 35 岁前要不要回学术界做博后

> 我现在 32 岁，在互联网公司做 AI 产品经理 5 年，月薪 5 万。在考虑要不要利用之前博士积累的研究背景，去申请 1-2 年的博后职位，回到学术界做研究。…

**第一条致命**：家庭月收入骤降导致入不敷出

你月薪从5万降到1.5-2万，妻子月薪1.2万，家庭月收入从6.2万降至2.7-3.2万，3岁孩子的开销无法覆盖，故必须动用储蓄，但储蓄耗尽后即破产。

**第一条避险**：与妻子做家庭财务对账

本周内（5/20-26）找一晚孩子睡后，和妻子用1小时列出家庭月固定支出（房贷/房租、孩子开销、日常消费等），并计算博后期间月收入2.7-3.2万下每月缺口。

完整报告：[case-03-back-to-academia.md](./case-03-back-to-academia.md)

### 4. 要不要花 5 万买 Mac Studio M5 Ultra 自部署 LLM

> 我是独立开发者，主业是用 AI 做工具。在考虑花 5 万买顶配 Mac Studio M5 Ultra（512GB 内存），用来本地跑大模型，减少对 API 的依赖。…

**第一条致命**：你低估了对API不可替代性的依赖

因为目前月开销仅200-500，即使涨到3000-5000，5万够烧100个月，本地跑节省有限，致使5万现金投入后失去应急缓冲，一旦产品失败则无退路。

**第一条避险**：计算本地跑模型 vs API 的实际成本对比表

本周二前，用 Excel 列出 3 个场景：当前用量（月 500 元）、预期用量（月 5000 元）、极端用量（月 2 万元）。分别计算 3 年内本地跑（5 万硬件 + 电费 + 维护）和 API 的总成本，并标出盈亏平衡点。

完整报告：[case-04-buy-mac-studio.md](./case-04-buy-mac-studio.md)
