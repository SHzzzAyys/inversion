# Inversion v0.1 alpha · 用户使用指南

> 给你的朋友看这份。

## 这是什么

一个**反演推演**桌面工具。你输入一个正在考虑的决定（辞职、跳槽、读博、买房、结婚……），它会用 AI 列出 20 条最可能让这个决定失败的具体路径，每条带【致命】【警惕】【留意】标签 + 因果链；然后你可以为关键的"致命"路径生成本周可执行的避险动作。

**它不给你答案，它只给你看清失败的样子**——所以你能更冷静地做决定。

## 安装（30 秒）

1. 双击 `inversion-app_0.1.0_x64-setup.exe`
2. 按提示走完（建议选「为我安装」不需要管理员）
3. 启动 Inversion（开始菜单 / 桌面快捷方式）

**约 5MB 安装空间，启动 < 2 秒。**

## 首次配置（1 分钟）

App 首次启动会要求你填一个 **DeepSeek API key**。

**为什么需要 key**：alpha 版是 BYOK 模式（Bring Your Own Key）。我们不收集你的决策数据，但 AI 推演需要调用大模型——所以你用自己的 key 调用，按需付费。

**如何申请**：
1. 去 https://platform.deepseek.com/api_keys
2. 注册（微信/邮箱），完成实名（5 分钟）
3. 新账户**送 ¥5 体验额度**（够 250 次推演）
4. 点「创建 API Key」，复制
5. 回到 Inversion，粘贴到输入框，点「测试并保存」

**Key 存哪里**：你的 Windows Credential Manager（系统钥匙串），别人偷不到。不上传我们任何服务器。

## 用法（3 分钟体验完整流程）

### 第一步：输入决策
在主页输入一个真实的决定，**至少 20 字**。越具体越好——年龄、城市、月薪、家庭、关键数字都写上。

不知道写什么？点下方 **「博士退学」/「回老家考公」/「AI 创业跳槽」** 任一示例直接体验。
或展开 **「或从模板开始」**，从 8 个常见决策类型里选一个填空模板。

按 **Ctrl + Enter** 提交。

### 第二步：澄清问答（30 秒）
AI 会问你 3 个针对性的澄清问题。每个回答一两句话就够。回答得越具体，后面的失败路径就越准。

### 第三步：等 20 条路径（30-60 秒）
AI 会流式生成 20 条按"严重度"排序的失败路径。出完后你能看到 `致命 X | 警惕 Y | 留意 Z` 的统计。

### 第四步：展开 + 生成避险
点任意一条路径展开，看完整因果链。
点击红色按钮 **「生成本周可执行的避险清单」**，AI 会针对这条路径出 3-5 条**本周可执行的具体动作**（含数字、时间、人、地点、动作）。
勾选完成的动作 → 系统会记录时间戳，方便你 30 天后回头看。

### 第五步：保存 + 导出
- **自动保存**：每次推演完都会自动落盘到 `%APPDATA%\com.inversion.app\decisions.json`
- **Markdown 导出**：results 页右上角点「📋 导出 Markdown」，整份报告复制到剪贴板，粘到任何编辑器
- **历史档案**：Header 右上角 「📁」 进入历史，看过去所有推演
- **30 天 check-in**：30 天后回头看，AI 列的失败路径有没有真的发生

## 快捷键

- `Ctrl + Enter` — 提交决策 / 提交澄清 / 保存 check-in
- `Ctrl + K` — 打开历史档案
- `Esc` — 返回主页 / 收起所有展开的路径

## 一些"哲学"

- **它不是 ChatGPT 套壳**。我们只做一件事：把你脑子里的乐观偏差撬开，让你看清失败路径。
- **它不给你建议**。它列出失败路径 + 避险动作，决定权永远在你。
- **它不替你思考**。它的核心价值是"扩大你的思考面"，让你的决定建立在更全的信息上。
- **它不预测未来**。失败路径是"最可能"，不是"会发生"。
